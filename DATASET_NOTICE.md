
# Dataset Attribution and Licensing

## Dataset Information

Dataset Name: IBM Telco Customer Churn

Original Source:
https://github.com/IBM/telco-customer-churn-on-icp4d

Dataset File:
https://github.com/IBM/telco-customer-churn-on-icp4d/blob/master/data/Telco-Customer-Churn.csv

## Dataset Description

The dataset contains:
- 7,043 customer records
- 21 columns
- Customer subscription information
- Billing information
- Customer churn labels

## Usage

This dataset is used for educational research,
machine learning development, and demonstration
of customer churn prediction.
